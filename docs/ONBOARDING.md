## Getting Started

1. **Clone the repository:**

   ```bash
   git clone <repository_url>
   cd shadow-block
   ```

2. **Backend Setup:**
   See `backend/README.md` for instructions on setting up the Python environment and running the server.

3. **Frontend Setup:**
   See `frontend/README.md` for instructions on installing NPM dependencies and running the Vite dev server.
